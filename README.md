## builds

- [steam-desktop-startup-movies](https://github.com/tuan-cre/steam-desktop-startup-movies) — Millennium plugin that plays startup movies on Steam desktop launch, like Steam Deck. TypeScript.
- [hypr-mcp](https://github.com/tuan-cre/hypr-mcp) — MCP server so agents can see and drive Hyprland: screenshots, mouse/keyboard, windows, OCR. Python.
- [chilli-plant-doctor](https://github.com/tuan-cre/chilli-plant-doctor) — Real-time chili plant disease detection with YOLO on mobile (Flutter + TFLite). Python.
- [waybar-vis](https://github.com/tuan-cre/waybar-vis) — PipeWire audio spectrum visualizer for Waybar via FFT → Unicode blocks. C.
- [vlxd-laravel](https://github.com/tuan-cre/vlxd-laravel) — Construction-materials e-commerce: Laravel 13, MySQL, cart/checkout, multi-warehouse, loyalty tiers. PHP.
- [unisupport](https://github.com/tuan-cre/unisupport) — University IT help-desk SaaS. NestJS 11 + React 19 monorepo. TypeScript.
